# PyQuantumKit支持的量子子例程

本页给出了PyQuantumKit支持的量子子例程及其对应的`apply_subroutine`函数的调用字符串，供用户查阅。**请注意，当需要将包含量子子例程的量子线路应用到具体量子开发框架时，需要注意目标量子开发框架是否支持该子例程。** 与量子门不同，如果目标平台不支持某个子例程，PyQuantumKit会直接报“不受支持”的错误，不会为了兼容性做等价性变换。

## 量子傅里叶变换系列子例程

### 标准量子傅里叶变换
- apply_subroutine函数的调用字符串（不区分大小写，下同）： `'QFT'`

### 末端不含交换门的量子傅里叶变换
- apply_subroutine函数的调用字符串： `'QFT_NS'`

### 标准逆量子傅里叶变换
- apply_subroutine函数的调用字符串： `'IQFT'`

### 起始不含交换门的逆量子傅里叶变换
- apply_subroutine函数的调用字符串： `'IQFT_NS'`
