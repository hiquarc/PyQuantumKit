# 欢迎使用PyQuantumKit

作为想要使用量子计算技术的开发者，你是否正在面临如下问题：

- 国际通用的IBM量子硬件平台，无法在国内使用；
- 想要使用国内的量子硬件平台，但不同的平台拥有各自自独立的软件包和框架，切换到另一个平台时，不得不重新编写代码；
- 不同量子平台支持的量子门和提供的API有区别，平台之间代码转换需要花费额外的精力进行适配；
- 写好量子线路后，没有工具可以检验是否存在编写问题；
- **目前编写量子程序的层级较低，需要像写汇编语言一样操纵单个量子比特。**

## 设计目标

为了解决上述问题，实现量子计算应用的跨（量子硬件）平台开发，我们设计了PyQuantumKit。它是一个基于Python的跨平台量子程序开发工具，也可用作构建跨平台量子应用的中间件。PyQuantumKit的设计目标包括：

- 提供**统一的方式**在不同的**基于Python**的量子开发框架上构建量子线路，实现**代码复用**；
- **提供高级语言级量子编程能力；**
- 软件架构具有**扩展性**，未来可方便地添加更多的功能和量子开发框架的支持；
- 为量子软件新技术的研究提供实验平台。

## 目前支持的框架
PyQuantumKit v.0.1.6和v.0.2.0beta目前支持如下量子开发框架：

- **IBM Qiskit**
- **本源量子QPanda3**
- **北京量子院Quafu**
- **Cqlib**

## 特色功能

- **提供高级语言级量子程序设计；**
- 编写一次代码，即可在多个量子平台上运行；
- 生成量子线路的矩阵符号表示。
