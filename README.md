# PyQuantumKit简介

作为想要使用量子计算技术的开发者，你是否正在面临如下问题：

- 国际通用的IBM量子硬件平台，无法在国内使用；
- 想要使用国内的量子硬件平台，但不同的平台拥有各自自独立的软件包和框架，切换到另一个平台时，不得不重新编写代码。此外不同量子平台支持的量子门和提供的API有区别，平台之间代码转换需要花费额外的精力进行适配。
- **目前量子编程的层级较低，需要像写汇编语言操作寄存器一样操作单个量子比特，且运行结果为0/1串，需要用户自行从中解读信息。要是量子应用开发能像写C或Python一样编写高级语言代码，然后再编译为量子线路，并且能自动从运行结果0/1串中解读信息就好了。**
- 写好量子线路后，没有工具可以检验是否存在编写问题；

## 设计目标

为了解决上述问题，实现高级语言级量子编程和量子计算应用的跨（量子硬件）平台开发，我们设计了PyQuantumKit。它是一个基于Python的跨平台量子程序开发工具，也可用作构建跨平台量子应用的中间件。PyQuantumKit的设计目标包括：

- **提供高级语言级量子编程能力，用户可以利用Python的语法来编写高级语言级量子程序；**
- **提供多种量子数据类型，并支持用户基于Python语法来自定义量子数据类型；**
- 高级语言级量子程序可以编译为不同的量子开发框架上构建量子线路，实现**跨平台开发**；
- 软件架构具有**扩展性**，未来可方便地添加更多的功能和量子开发框架的支持；
- 源代码完全开源，为量子软件新技术的研究提供实验平台。

## 特色功能

- **高级语言级量子编程：** 提供基于Python的高级语言级量子程序设计，提供量子数据类型支持（数组、结构体、元组、联合体等），可实现对运行结果0/1串的解读（v.0.2新增功能）；
- **跨平台开发：** 编写一次代码，可编译为不同量子开发框架上的量子线路，进而实现在不同量子平台上运行；
- **符号表示：** 生成量子线路的矩阵符号表示（基于sympy）。

# 安装和使用

使用`pip install`命令可安装PyQuantumKit

```sh
pip install pyquantumkit
```

PyQuantumKit要求Python版本>=3.8，且依赖如下Python包：

- sympy >= 1.8
- numpy >= 1.22.0
- packaging >= 20.0

通常，PyQuantumKit需要与受支持的基于Python的量子开发框架（例如qiskit或pyqpanda3等）联合使用。可以在安装PyQuantumKit的同时安装受支持的量子开发框架，例如，使用如下命令在安装PyQuantumKit的同时安装qiskit：

```sh
pip install "pyquantumkit[qiskit]"
```

使用`git clone`命令将PyQuantumKit仓库复制到本地：

```sh
git clone https://github.com/hiquarc/PyQuantumKit.git
```

用户文档参见：[https://pyquantumkit.readthedocs.io/](https://pyquantumkit.readthedocs.io/)

# 版本历史

**2026/11/12 v.0.2.1**

- 调整了代码翻译模块的编写规则，以适应用户自定义翻译脚本；
- 允许用户编写自定义翻译脚本，以支持将量子线路翻译到更多的量子编程语言或基于Python量子开发框架，也可修改内建的翻译脚本；
- 内建翻译脚本增加对OpenQASM 2.0语言的支持；
- 实验性引入量子子例程（Quantum Subruotine）概念。

2026/9/15 v.0.2.0

- 重磅更新：高级语言级量子编程（pyquantumkit.program模块）
- 对软件架构进行了改动，以支持高级语言级量子编程。之前用PyQuantumKit v.0.1.*编写的代码可能需要对模块名和函数名进行调整。

    - 调整了代码翻译模块的目录结构和检索方式；
    - 代表含有测量的量子线路相关的函数命名改为mixed_circuit（替换原有的program，因为program要用于高级语言级量子编程）；
    - program_check, program_relation模块更名为circuit_check, circuit_relation；

2026/4/15 v.0.1.6
- 为项目添加说明文档

2026/3/27 v.0.1.5
